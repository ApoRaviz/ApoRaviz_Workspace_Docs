# ApoRaviz Tools Case Studies

โฟลเดอร์นี้เก็บบทเรียนจาก `ApoRaviz_Tools`

กติกา:

```text
ApoRaviz_Tools/docs/ = requirement, architecture, commands เฉพาะโปรเจกต์
ApoRaviz_Workspace_Docs/projects/tools/ = case study จากโปรเจกต์จริง
nodejs/ = concept กลางที่ใช้ซ้ำได้ เช่น stream, CLI, test
backend/ หรือ nestjs/ = backend path ในอนาคต
```
