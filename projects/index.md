# Project Case Studies

โฟลเดอร์นี้เก็บบทเรียนจากโปรเจกต์จริงของ `ApoRaviz_*`

ต่างจาก `angular/`, `nodejs/`, `backend/` ที่สอน concept กลาง โฟลเดอร์นี้ใช้เล่า case study จากงานจริง เช่น product thinking, business flow, UX decision, bug/decision เฉพาะโปรเจกต์ และวิธีเอาความรู้ไปเล่าเป็นผลงาน

## Current Cases

- [MooPing Reward Learning Case Study](mooping/)
- [ApoRaviz Tools Case Studies](tools/)

## Rule

```text
angular/          = Angular/Tailwind concept กลาง
nodejs/           = Node.js/CLI/file processing concept กลาง
backend/          = backend architecture concept กลาง
git/              = Git command กลาง
projects/<name>/  = บทเรียนจากโปรเจกต์จริง
```

ถ้า project case เริ่มสอน concept ที่ใช้ซ้ำได้ ให้สรุป concept นั้นกลับไปที่หมวดกลางด้วย
