# Project Case Studies

โฟลเดอร์นี้เก็บบทเรียนจากโปรเจกต์จริงของ `ApoRaviz_*`

ต่างจาก `angular/` ที่สอน concept กลาง โฟลเดอร์นี้ใช้เล่า case study จากงานจริง เช่น product thinking, business flow, UX decision, bug/decision เฉพาะโปรเจกต์ และวิธีเอาความรู้ไปเล่าเป็นผลงาน

## Rule

```text
angular/          = Angular/Tailwind concept กลาง
git/              = Git command กลาง
projects/<name>/  = บทเรียนจากโปรเจกต์จริง
```

ถ้า project case เริ่มสอน Angular/Tailwind/Git concept ที่ใช้ซ้ำได้ ให้สรุป concept นั้นกลับไปที่ `angular/` หรือ `git/` ด้วย
