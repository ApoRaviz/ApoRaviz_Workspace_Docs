# Angular Lessons

โฟลเดอร์นี้เก็บบทเรียนแบบ flow

lesson ไม่ใช่แค่คำอธิบาย syntax แต่ต้องตอบว่า "สิ่งนี้ทำงานเป็นลำดับอย่างไร"

ตัวอย่างบทเรียนที่ควรอยู่ที่นี่:

- Angular app เริ่มทำงานจากตรงไหน
- `ng serve` อ่านไฟล์อะไรบ้าง
- `main.ts` bootstrap app อย่างไร
- `signal` เปลี่ยนแล้ว UI update อย่างไร
- `inject()` ขอ service จาก Angular อย่างไร
- SSR กับ hydration ทำงานร่วมกันอย่างไร
- `setInterval` ต้อง cleanup อย่างไร

กติกา:

- เริ่มจากภาพจำง่าย ๆ
- มี flow ทีละขั้น
- มี code ตัวอย่างสั้น ๆ
- อธิบาย code ทีละบรรทัด
- link ไป concept ที่เกี่ยวข้อง
