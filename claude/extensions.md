# Claude Code — Skill / Plugin / MCP ต่างกันยังไง (+ ตัวอย่างส่วนเสริมยอดฮิต)

หน้านี้แก้ความเข้าใจผิดที่เจอบ่อยสุดเวลาเห็นชื่อส่วนเสริมของ Claude Code หลาย ๆ อัน แล้วเหมาโหลว่า "ทุกอันคือ skill"

> หน้านี้ต่อยอดจาก [Claude Code — คู่มือคำสั่งและความสามารถ](./index.md) ที่อธิบาย 3 ชั้น (slash command / skill / tool) — ที่นี่เพิ่มอีก 2 ชั้นที่เป็น **ช่องทางแจกจ่าย/เชื่อมต่อ** คือ plugin กับ MCP

## ภาพจำ — เครื่องมือ / กล่องเครื่องมือ / ปลั๊กต่อเครื่องอื่น

```text
skill       = เครื่องมือ 1 ชิ้น   -> ความสามารถเฉพาะทาง 1 อย่างที่ Claude เรียกใช้
plugin      = กล่องเครื่องมือ     -> ห่อ skill/command/hook/MCP หลายอันไว้ ติดตั้งทีเดียว
MCP server  = ปลั๊กต่อเครื่องอื่น -> สายเชื่อม Claude ออกไปหาเครื่องมือ/ข้อมูลนอกตัว
```

**เข้าใจผิดบ่อยสุด:** เห็นชื่อไหนก็เรียก "skill" หมด — จริง ๆ Superpowers เป็น plugin, Context7 เป็น MCP server ไม่ใช่ skill

## คำแปลแบบคนธรรมดา

- **Skill** คือ "ทักษะติดตัว" ของ Claude เรื่องใดเรื่องหนึ่ง เช่น "รู้วิธีเทสต์เว็บ" หรือ "รู้วิธีสร้าง skill" — Claude หยิบมาใช้เองตามงาน หรือคุณพิมพ์ `/ชื่อ` เรียกก็ได้ เนื้อในคือไฟล์ชุดคำสั่ง (`SKILL.md`) ที่โหลดเข้ามาตอนใช้
- **Plugin** คือ "แพ็กเกจ" ที่คนอื่นทำไว้ให้ ข้างในอาจมีหลาย skill + slash command + hook + การตั้งค่า MCP รวมกัน ติดตั้งครั้งเดียวได้ของหลายอย่าง (มักมาจาก plugin marketplace)
- **MCP server** (Model Context Protocol) คือ "โปรแกรมภายนอก" ที่รันแยกแล้วเปิดช่องให้ Claude เรียกใช้ tool/ดึงข้อมูลจากมัน เช่น ต่อ database, ดึง doc, คุมเบราว์เซอร์ — จัดการผ่าน `/mcp`

## technical term

| ศัพท์ | ความหมายสั้น |
|---|---|
| `skill` | ความสามารถเฉพาะทาง โหลดจาก `SKILL.md` ตอน Claude เรียกใช้ |
| `plugin` | bundle ที่รวม skill + command + hook + MCP config แจกผ่าน marketplace |
| `MCP` (Model Context Protocol) | มาตรฐานให้ Claude เชื่อมต่อเครื่องมือ/ข้อมูลภายนอกแบบ tool |
| `MCP server` | ตัวโปรแกรมที่ทำตาม MCP รันแยกจาก Claude Code |
| `hook` | คำสั่งที่ harness รันอัตโนมัติเมื่อเกิด event (เช่นก่อน/หลังใช้ tool) |

## จับ 6 ตัวยอดฮิตเข้าช่องให้ถูก

| ชื่อ | จริง ๆ คือ | ทำอะไร | เรียกใช้ยังไง |
|---|---|---|---|
| **Superpowers** | 🧩 Plugin | เพิ่มชุด skill ช่วยวางแผน เขียนโค้ด ทำงานเป็นขั้นตอน (brainstorm → plan → build) | ติดตั้ง plugin แล้ว skill ข้างในโผล่เป็น `/...` |
| **Context7** | 🔌 MCP server | ดึง doc เวอร์ชันล่าสุดของ library มาให้ Claude อ้างอิง (กัน API เก่า/มั่ว) | ตั้งค่าใน `/mcp` แล้ว Claude เรียก tool ของมันเอง |
| **MCP Builder** | ⚡ Skill | ช่วยออกแบบ + สร้าง MCP server ตัวใหม่ | Claude เรียกเองตอนงานเข้าเรื่อง หรือพิมพ์ `/` เรียก |
| **Skill Creator** | ⚡ Skill | ช่วย scaffold + เขียน skill ของเราเอง (`SKILL.md`) | เรียกตอนอยากสร้าง skill ใหม่ |
| **Webapp Testing** | ⚡ Skill | ให้ Claude เปิดเบราว์เซอร์จริงไปคลิก/กรอก/ตรวจผลเว็บ | เรียกตอนอยากเทสต์ UI ในเบราว์เซอร์ |
| **Claude-Mem** | 🧩 Plugin | ให้ Claude จำข้อมูลข้ามรอบการทำงาน (ใช้ hook + MCP + ที่เก็บ local) | ติดตั้ง plugin แล้วมันทำงานเบื้องหลังผ่าน hook |

จัดกลุ่มอีกที:

```text
Skill      : MCP Builder, Skill Creator, Webapp Testing
Plugin     : Superpowers, Claude-Mem
MCP server : Context7
```

## จุดที่มักงง

- **"เป็น plugin แต่ทำไมเรียกด้วย `/` เหมือน skill?"** — เพราะ plugin *ห่อ* skill ไว้ข้างใน สิ่งที่คุณพิมพ์เรียกคือ skill ในกล่อง ไม่ใช่ตัว plugin เอง
- **plugin ต่างกับ MCP ยังไง** — plugin เป็นวิธี *แจกจ่าย/ติดตั้ง* ของหลายอย่างพร้อมกัน (อาจมี MCP อยู่ในนั้นด้วย) ส่วน MCP เป็นวิธี *เชื่อมต่อ* ออกไปหาโปรแกรมภายนอก คนละมิติกัน คือ plugin หนึ่งตัวอาจตั้งค่า MCP ให้เลยก็ได้ (เช่น Claude-Mem)
- **skill vs tool** — tool คือความสามารถพื้นฐานที่ Claude มีติดตัว (อ่าน/แก้ไฟล์ รัน command) ส่วน skill คือ "ชุดวิธีทำ" เฉพาะทางที่โหลดมาเสริม
- **ของจริงในเครื่องต่างกันได้** — ชุด skill/plugin/MCP ขึ้นกับสิ่งที่ติดตั้งไว้ พิมพ์ `/` ดูเมนู หรือ `/mcp` ดู MCP ที่ต่ออยู่จริง

## self-check

1. Context7 เป็น skill หรือ MCP server? → *MCP server* (สายเชื่อมไปดึง doc ภายนอก)
2. ถ้าอยากได้ "ทักษะเทสต์เว็บผ่านเบราว์เซอร์" ต้องหาแบบไหน? → *skill* (Webapp Testing)
3. Superpowers ให้ของหลายอย่างในการติดตั้งครั้งเดียว เพราะมันคืออะไร? → *plugin* (กล่องที่ห่อ skill/command หลายอัน)
4. จะดูว่าเครื่องเราต่อ MCP อะไรไว้บ้าง พิมพ์คำสั่งอะไร? → `/mcp`

## สรุปจำสั้น ๆ

```text
skill  = เครื่องมือ 1 ชิ้น  (MCP Builder, Skill Creator, Webapp Testing)
plugin = กล่องเครื่องมือ    (Superpowers, Claude-Mem)
MCP    = ปลั๊กต่อเครื่องอื่น (Context7)
เห็นชื่อแปลก ๆ อย่าเหมาว่า skill — ดูก่อนว่ามันเป็น "เครื่องมือ / กล่อง / สายเชื่อม"
เช็คของจริง: พิมพ์ /  (skill/command)  และ  /mcp  (MCP server)
```
